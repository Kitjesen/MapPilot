- 组件采用 CSS Modules 命名规范，每个 `.tsx` 文件对应同名的 `.module.css` 文件以实现样式作用域隔离。
- 自定义 Hooks（如 `useSSE`, `useCamera`）统一放置在 `src/hooks/` 目录下，负责封装复杂的浏览器 API 交互与状态同步逻辑。
- 所有后端 API 调用集中定义在 `src/services/api.ts` 中，提供统一的错误处理（`GatewayApiError`）与请求标识生成。
- 类型定义集中在 `src/types/index.ts`，涵盖 SSE 事件结构、API 响应模型及业务实体接口，确保全链路类型安全。
