- **技术栈**: 采用 React 19 + TypeScript + Vite 架构，使用 Three.js 进行 3D 场景渲染，通过 CSS Modules 实现组件级样式隔离。
- **数据流设计**: 核心依赖 `useSSE` Hook 建立与服务端的 Server-Sent Events (SSE) 长连接，实时接收里程计、安全状态及任务进度；辅以 `services/api.ts` 封装的 RESTful 客户端处理指令下发与状态快照拉取。
- **布局架构**: `App.tsx` 作为顶层路由控制器，管理登录鉴权与多标签页（Console/Scene/Map/SLAM）切换；`FloatingWidget` 组件提供可拖拽、可调整大小的模块化面板布局，支持用户自定义工作台。
- **通信机制**: `vite.config.ts` 配置了针对 `/api`, `/ws`, `/mcp` 等路径的开发代理，将前端请求转发至后端网关（默认 localhost:5050），实现前后端解耦开发。
