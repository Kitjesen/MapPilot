- 所有功能模块必须继承 `core.module.Module` 基类，并通过类型注解（如 `image: In[Image]`）声明输入输出端口，由基类在初始化时自动实例化。
- 模块间的远程过程调用方法需使用 `@rpc` 或 `@skill` 装饰器标记，以便 `MCPServerModule` 或 `RPCClient` 进行动态发现与代理。
- 系统组装采用声明式 `Blueprint` 模式，通过 `.add()` 注册模块、`.wire()` 或 `.auto_wire()` 建立连接，最后调用 `.build()` 生成 `SystemHandle`。
- C++ 算法节点通过 `NativeModule` 包装为 Python 模块，配置 `NativeModuleConfig` 指定二进制路径及 ROS2 参数，由 Python 层统一管理其进程生命周期。
