- 所有 API 响应均封装为带有 `raw` 字段的 `@dataclass` 类型（如 `CommandResult`, `HealthStatus`），兼顾类型安全与原始数据访问。
- 内部 HTTP 请求统一通过 `_get` 和 `_post` 私有方法处理，自动注入 `X-API-Key` 认证头并解析 JSON 响应。
- 命令类操作（如 `go`, `stop`）统一返回 `CommandResult` 对象，通过检查 `ok` 或 `success` 字段判断执行状态。
- 客户端类均实现上下文管理器协议（`__enter__`/`__exit__` 或 `__aenter__`/`__aexit__`），确保会话资源的自动释放。
