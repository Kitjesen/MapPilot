- **核心分层**：模块以 `client.py`（基于 `urllib` 的同步客户端）和 `async_client.py`（基于 `aiohttp` 的异步客户端）为双核心，共享定义在 `client.py` 中的 Typed Dataclass 模型（如 `RobotState`, `Position`）。
- **扩展接口**：`mcp.py` 封装了基于 JSON-RPC 2.0 的 AI Agent 交互层，通过 `httpx` 调用远程工具；`config.py` 提供统一的连接配置数据类。
- **入口点**：`__init__.py` 导出主要客户端类和类型定义；`cli.py` 基于 `argparse` 提供命令行快速调试工具。
- **依赖策略**：同步客户端仅依赖 Python 标准库以确保零依赖运行；异步功能和 MCP 客户端分别通过可选依赖 `aiohttp` 和 `httpx` 实现。
