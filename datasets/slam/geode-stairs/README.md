## 实际 bag 检查

完整索引可读：3,494个未压缩chunk；包时间跨度 **345.527792229 秒**。

| 实际话题 | 类型 | 条数 |
| --- | --- | ---: |
| `/velodyne_points` | `sensor_msgs/PointCloud2` | 3,456 |
| `/imu/data` | `sensor_msgs/Imu` | 34,556 |
| `/left_camera/compressed` | `sensor_msgs/CompressedImage` | 3,455 |
| `/right_camera/compressed` | `sensor_msgs/CompressedImage` | 3,455 |

已读前2帧点云和200条IMU实际载荷。原始点字段是 `x/y/z/intensity` float32、`ring` uint16、`time` float32，每点22字节。点时间存在负值（首帧约−0.09953至+0.00131秒），转换不能当作无符号帧内偏移直接复制。两帧都有非有限坐标，原包标记 `is_dense=false`；转换时必须显式处理并记录，不能盲目沿用“全点有限”的假设。详情见检查JSON。初始200条加速度范数中位数 **9.767244 m/s²**，相邻IMU头时间差中位数 **9.762257 ms**；这支持按SI原始值继续核对，而不是沿用AIST的g单位缩放。最终转换还需核对时间字段语义、全流时序和外参，不在本轮假设完成。

## 参考轨迹的能力边界

**这不是独立动捕/全站仪连续轨迹真值。** 发布者说明楼梯轨迹由 PALoc 将扫描对齐到 Leica RTC360 参考地图得到。Alpha 的轨迹有位置和四元数，可做同参考条件下的评价，但不能当作与LiDAR估计完全独立的绝对真值，也不能据此给出无条件的定位精度结论。

原始轨迹时间 `1705542304.08553` 至 `1705542648.66169` 秒，覆盖344.57616秒，三维轨迹累计约301.05954米。参考Z跨度23.62502米，支持检查真实多层高度变化；不将它称为逐点地面或动态语义标注。

官方 `stairs.las` 参考地图为15,633,240,915字节，本轮未下载；其官方入口记录在manifest中。当前只补一个3.975GB录制和必要标定、轨迹。Gamma虽然包更小，但官方明确其楼梯轨迹因Avia窄视场漂移缺失，因此本轮选择Alpha。

## 2026-10-20 原生回放更新

完整 VLP16 + Xsens MTi30 录制已转换并回放。原始 3456 帧点云和 34556 条 IMU 均被读取；约 2814 万非有限点不参与几何，247 帧保留原始最大时刻的 NaN 返回以维持扫描末端。前一版载体删除该末端造成最多 20.939 ms 偏移，相关旧结果已标记 `uncertified-end-timing-*` 并撤为非正式基线。

修正时间载体后，默认设置仍发布 749 个姿态后进入 `LOST: ltlio_velocity_out_of_bounds`；仅离线关闭速度门槛的诊断输出 2033 个姿态后严重发散，最终为 `LOST: ltlio_position_covariance_out_of_bounds`。完整读取输入不是全程定位成功，未改变生产参数来通过这条测试。

PALoc/地图配准派生的参考不能当独立密集真值，分发轨迹的 IMU/LiDAR 参考点尚未完全核定。默认前段 749 个共同时刻，在 IMU 参考假设下条件位置 RMSE 约 1.326 m；另按发布外参转 LiDAR 的结果分别报告，不选择较小值作为真值。该分数只覆盖约 75 秒，不能代表完整约 345 秒录制。

修正、精确配置、全量计数、覆盖范围、两种参考点条件、旧失败撤销及最终输出见 [本轮 GEODE 记录](../../../build/scene-next-20261020/new-data/README.md)。没有新增 ROS、rosbags、机器人运行依赖或产品级 Velodyne 支持。
