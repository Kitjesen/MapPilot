# FactoryPark surface sources

Downloaded 2026-10-17 from Poly Haven's public asset API. License: **CC0-1.0**,
https://polyhaven.com/license. Each set includes 2K base color, roughness and
DirectX normal maps; the normal textures are imported without sRGB conversion.

- https://polyhaven.com/a/asphalt_02
- https://polyhaven.com/a/concrete_floor_worn_001
- https://polyhaven.com/a/box_profile_metal_sheet
- https://polyhaven.com/a/aerial_grass_rock

`sources.json` records the exact upstream download URL and file size per channel.
Source images remain unmodified. Desaturation, tint and real-world repeat sizes
are applied in Unreal materials, not baked into replacement bitmap files.

These are visual surface materials, not new collision geometry and not extracted
assets from any commercial game.
