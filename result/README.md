# LingTu 实验结果

这里统一归档两批静态三维导航实验：

- [连续地形全量结果](terrain-exploration-20261117/README.md)：36 个场景、86 组请求；72 组返回路线，14 组无路线，其中 6 组是预设负例的正确拒绝，8 组是尚未解释清楚的无路线。逐请求路径从 `terrain-exploration-20261117/data/manifest.csv` 查起。
- [导航论文图包](navigation-paper-20261117/README.md)：早先的 31 个场景、117 组请求、122 张论文图；其中 99 组返回路线，18 组没有路线（14 组 `rejected`、4 组 `probe_rejected`）。`validation.json` 记录了图包校验结果。

合并两批档案共有 **67 个场景、203 组请求**：**171 组返回路线，32 组没有路线**。这个合并统计只表示静态规划返回值，不把“正确拒绝”混成“算法失败”。连续地形批次的原始规划 JSON、几何复核、OctoMap、日志和复现脚本都在第一个目录；论文图包的源数据和图册都在第二个目录。两批都只是静态全局规划／几何证据，不是 MuJoCo 动力学或 NX 实机运动验收。
