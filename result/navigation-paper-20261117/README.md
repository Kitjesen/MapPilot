# LingTu 导航论文图包 · 2026-11-17

本图包从本轮保存的地图几何和原始路线坐标绘制。涵盖 **31 个场景、117 组请求**：
99 组返回经过几何复核的 Rust 路线，18 组未返回路线。

## 高度结论与使用范围

| 指标 | 本轮证据 |
| --- | --- |
| 配置的单步高度上限 | 0.45 m |
| 单级台阶已验证通过的最高测试值 | 0.45 m，正反方向均通过静态全局规划与几何复核 |
| 0.50 m 单级台阶 | 正反方向均无路线 |
| 连续多级楼梯的已测单级高度 | 0.30 m |
| 多层场景已测总爬升 | 4.80 m；不能写成单级高度 |
| 已完成上下楼的 MuJoCo 物理仿真 | 此前每级 0.06 m、12 级场景；不是本图包中 0.45 m 台阶的物理证明 |

本轮没有再次运行机器人动力学或 NX 实机测试。蓝色曲线是身体参考点路线，
不表示足端轨迹、实际运动录像或硬件攀爬极限。45 cm 是当前配置与已测场景的
结果，不是通过这组实验测定的机器人真实最大攀爬能力。

35° 场景返回的绕行路线虽然经过几何复核，一个方向耗时 101.503 s，反向
22.194 s。图中不能把它描述为实时规划已达标，也不能把场景名义坡度当作每一段
路线的坡度。计时发生于本机任务运行环境，未做隔离性能对照。

## 文件选择

- `index.html`：离线图册目录，可直接打开；每张图有 PNG、PDF、SVG 链接和英文图注。
- `figure-atlas.pdf`：全部 122 张图的多页浏览版。
- `pdf/`：矢量 PDF，优先用于 LaTeX 和论文排版，字体嵌入。
- `svg/`：矢量 SVG，可在支持 SVG 的编辑器中修改文字、颜色和线条；字体保留为文本。
- `png/`：600 dpi 高清 PNG，适合 Word、演示及投稿系统预览。
- `originals/`：此前展示的中文原图，包括起步修改前、修改后、距离扫描和跨层总览。
- `figures.tex`：五张正文组合图的 LaTeX 插入片段。
- `captions_zh.md`：正文组合图中文图注。
- `index.csv`、`figures.json`：全部图的名称、英文图注及来源请求编号。
- `routes.csv`：原始路线坐标，单位米；未返回路线的请求没有人为补出的路线点。
- `data.json`：冻结的场景实体、起终点、路线、状态、参数和几何复核结果。
- `startup-before.json`：起步策略调整前的同输入结果。
- `export.py`：根据上述冻结数据重新生成全套图，不依赖运行中的 Web 服务。

## 绘图规范

- 白底、统一色盲友好配色；蓝色实线表示正向／当前路线，橙色虚线表示反向路线。
- 绿色圆点为起点，橙色星标为请求目标。双向组合图的标记只表示正向请求，避免重叠。
- 正交三维投影，XYZ 使用相同的米制尺度，没有夸大高度。
- 地图实体透明绘制；路线在前景显示，以便跨层比较，不能用视觉遮挡判断碰撞。
- 多层总览省略外围墙体；独立图保留完整场景实体。透明度和视角是绘图选择，未改变地图与路线数据。
- 没有平滑、插值或移动原始路线点；未返回路线时只展示地图与请求端点。
- 轴标签约 8 pt、刻度约 7 pt、子图标题约 9 pt；组合图画布约 7.2 inch 宽，独立图约 3.6 inch 宽。
- PNG 按 600 dpi 导出；矢量图不受该像素分辨率限制。裁切边界包含留白以保留三维轴标签。

## 重新生成

在 LingTu 项目环境运行：

```powershell
uv run python docs/media/navigation-paper-20261117/export.py
```

脚本使用现有 `matplotlib` 和 `numpy`，没有新增项目依赖。修改数据后应重新核对结果范围；
仅调整排版时可修改脚本中的样式参数。

LaTeX 主文档需要 `graphicx`，并把本图包 `pdf/` 目录加入 `\graphicspath`，再使用
`figures.tex` 中的片段。按期刊最终单栏／双栏宽度检查文字尺寸，避免把文字再次压得过小。
