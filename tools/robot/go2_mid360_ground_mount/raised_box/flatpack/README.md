# 六件平放螺钉拼装试装原型

用户在 2026-09-29 明确选择“平放打印的板件＋螺钉组装”。本目录保留独立衍生件，不覆盖 V7 封闭箱体或上一版开窗框架。

六件：`left_side`、`right_side`、`base`、`lid`、`left_foot`、`right_foot`。STL 已按各自平放方向输出，单位毫米。侧板外侧贴床，接头向上加厚；顶板/底板平放；两个贴合垫座的平面朝下打印。支撑设为关闭，螺钉孔和螺母入口仅有约4.5–8mm的小跨度桥接，仍须检查实际切片。

侧板主要厚4mm，四处接头局部16mm；底板4mm；顶板5mm。底板与侧板有两组定位舌，插槽每侧名义0.2mm间隙。侧板上的M4螺母从内侧开口滑入，不能从封闭端硬压。

## 装配

1. 在每块侧板四个接头内分别放入M4六角螺母，共8颗（槽对边7.6mm、厚3.6mm；先试配实际螺母）。
2. 两个贴合垫座放在机身两侧原名义M3孔位置，平面朝上；底板放在垫座上。机身两孔仍为58.5mm名义孔距，未在实机确认。
3. 两颗机身M3螺钉从底板上方经金属平垫片、底板和垫座拧入机身。此版螺钉夹持厚度在孔中心约14.75/14.78mm，再加金属垫片厚度。按机身实际可用孔深选螺钉，不能直接复用旧短螺钉，也不能顶底强拧。
4. 两侧板定位舌插入底板槽，从底板下方以4颗M4×16配平垫片拧入侧板下接头。建议先在工作台试装侧板与底板，再按实际操作空间决定整套上机顺序。
5. MID-360先以4颗M3×8安装到5mm顶板上，名义伸入设备3mm；按实际垫片厚度确认啮合。不得用M3×12，名义入孔7mm过深。
6. 雷达顶板放到两侧板倾斜顶面，用4颗M4×16配平垫片从上方拧入顶部接头螺母，交叉轻拧至贴合。确认底部机身M3仍能拆盖操作。

新增连接件共8颗M4×16、8颗M4六角螺母、8片M4金属平垫片。先检查现有紧固件规格。PLA接头不要过度拧紧；此版本为静态试装原型，不宣称通过抗振、冲击、温升或连续导航验证。
