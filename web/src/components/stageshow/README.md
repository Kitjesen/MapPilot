# Stageshow motion subset

Source: https://github.com/benjitaylor/skills at 299140fafd08df55a9c234e610c3f64af3f45531 (MIT; see LICENSE).
Roll, Collapse, their CSS and the reduced-motion hook are vendored. Closed application disclosures are inert and aria-hidden, including their exit animation. No Stage, scripted cursor, demo data or playback runtime is used by LingTu.
Local change: outgoing text is aria-hidden so assistive technology does not read obsolete and current statuses together.
The upstream hook implementation is kept intact; project ESLint excludes this vendor directory, while TypeScript and browser interaction checks include it.
