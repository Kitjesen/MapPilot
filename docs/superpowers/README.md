# Historical Implementation Plans

The documents under `docs/superpowers/plans/` are dated implementation plans
and review artifacts. They explain why earlier changes were proposed, but they
are not current runbooks or architecture contracts.

Use these current entry points first:

- [`docs/CURRENT.md`](../CURRENT.md) for the deployed runtime truth.
- [`docs/architecture/SYSTEM_DESIGN.md`](../architecture/SYSTEM_DESIGN.md) for
  product architecture.
- [`docs/REPO_LAYOUT.md`](../REPO_LAYOUT.md) for source ownership.
- [`docs/04-deployment/README.md`](../04-deployment/README.md) for field
  deployment and service operations.
- [`docs/plans/current-roadmap.md`](../plans/current-roadmap.md) for active work.

When a historical plan conflicts with current code or the documents above,
the current code and current-contract documents win.
