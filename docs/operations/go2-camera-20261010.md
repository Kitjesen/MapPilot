## Cause and change

The previous `nav/standard` Product did not declare the camera process or Host
camera module. The previous release also omitted `bin/realsense_capture`.
The connected hardware is an Intel RealSense D435i. The existing RobotConfig
correctly selects `realsense_native`, SDK serial `419522073370`. The V4L/USB
identifier `253843060949` differs; it must not replace the SDK device serial.
Direct SDK `--list-devices` confirmed the configured value.

The existing native backend was built against the already installed
librealsense 2.56.5 SDK and included in the complete package. ProductControl
then switched to the existing `nav/camera` variant. No camera daemon was
started independently of ProductControl, and no motion goal was submitted.
Camera-to-body extrinsics and depth navigation fusion are still unverified;
RGB preview does not change the LiDAR-based collision or localization inputs.

The webpage now renders one optional camera preview in the map's left control
area, with `object-fit: contain` to retain the complete frame. The toolbar
contains Show camera and Fullscreen map. Browser F11 retains that same preview;
the new Fullscreen API entry uses `document.documentElement` to include the
existing global Stop, collapses the inspector and restores it on exit.
Camera starts closed, and opening/closing it changes only display subscription.

## Operation

Open [LingTu](http://192.168.66.65:5050/), reload for the updated assets, click the
camera icon to show its preview, then Fullscreen map. Escape exits API
fullscreen and restores the inspector. The preview's close button stops its
visible subscription while the camera-enabled Product continues capture.

To select this mode through the supported lifecycle entry, on NX:

```sh
bash /opt/lingtu/current/scripts/lingtu switch nav \
  --robot unitree/go2 --env real --variant camera --map 903room_v5_raised \
  --set scan_planner.max_velocity_mps=0.2 \
  --set scan_follower.max_vx_mps=0.2 \
  --set scan_planner.max_acceleration_mps2=1.0 --json
```

Normal `nav/standard` intentionally has no camera. No global default Product
was changed merely to enable this session's preview. Local evidence is in
`build/go2-camera-20261010/`; remote build, install and switch logs are in
`/home/unitree/field-camera-20261010/`.
