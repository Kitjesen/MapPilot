# 地图处理与巡检点工作台实施计划

更新：2026-11-11。按用户要求逐项接入正式 Web、Gateway 和对应领域模块；完成并有验证后才勾选。

## 已确定的产品行为

- 中央地图直接编辑，沿用顶部紧凑工具栏、左右可隐藏面板。
- 完整点云显示是默认；精简显示只能由用户明确选择，交互过程中不自动切换密度。
- 原始地图保留；点云修改先预览、可撤销，另存后重建导航数据。
- 人工补面记录人工来源，不伪造激光射线或已观测自由空间。
- 巡检点属于明确的地图版本，有名称、所属区域、位置、朝向和到点动作。
- 按点名或区域名称查找；多个匹配显示候选，不任意选择机器人运动目标。
- 保存和配置不会启动机器人。执行复用既有巡检任务及原生导航链。

## 实施顺序与验收

- [x] 核对现有能力：点云草稿／另存重建、原生禁行区、原生巡检路线与采集动作、命名地点存储。
- [x] 人工补地面／墙面：在当前地图设定平面范围与高度，预览、撤销、保存；重载及导航地图重建保留人工几何和来源。首版支持 XY／YZ／XZ 平面，尚不支持任意倾斜面。
- [x] 导航区域：在当前地图框选并命名禁行范围、显示已保存区域、编辑与删除；玻璃障碍标注使用真实三维范围。两种类型均复用现有三维禁行约束。
- [x] 巡检点编辑：在地图选择位置、中文命名、归属区域、调整朝向；保存并重新加载。表面选点与机身目标高度明确区分。
- [x] 巡检点检索：按点名／区域检索，并在地图定位；接入既有地点／巡检入口。区域多匹配返回全部候选；未验证自然语言实机执行。
- [x] 到点动作：停留与已支持的采集动作配置，保存后供既有巡检执行器使用；不展示不可执行的动作。首版为停留加一个现有采集／检查动作，执行时仍核对服务能力。
- [ ] 显示与性能：实际渲染设备、完整／固定精简显示、显示点数；设备偏好不冒充实际显卡选择。
- [ ] 局部清洗：选区／整图作用范围，预览和保存语义一致，选区外点不变。
- [ ] 剖切与测量：XYZ 剖切、距离、高差和净宽测量；显示结果不授权运动。
- [ ] 选择增强：多边形、反选、可见面／贯穿选择，并清楚显示作用范围。
- [ ] 历史与对照：操作参数、撤销重做、原图／结果对照、人工添加和删除点统计。
- [ ] 后台处理与版本状态：进度、失败与取消；原始点云／处理点云／导航产物及生效版本集中展示。
