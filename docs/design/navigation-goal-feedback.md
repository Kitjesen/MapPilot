# 导航选点、朝向与拒绝反馈

2026-11-07。本轮范围是完整 Web 的单点导航交互，沿用已有预览和提交接口，不改变规划阈值、运动许可或 G20 的只读入口。

## 位置与朝向

1. 在同层／三维表面模式选定目标，保留当前高度换算语义。
2. 中心实点表示所选目标；淡圈仅表示到达范围，不是机体尺寸或地图选区。
3. 在“单点”模式按下选定位置，同一笔拖出朝向，松手后预览。轻点只留下位置，不预设朝向；角度也可直接输入。缺少明确朝向时禁止预览和提交。
4. 只有显式“开始导航”才下发目标。拖动、修改朝向、松手和预览均不下发运动。
5. “浏览”模式保留普通拖动及双指缩放，单点模式保留右键浏览。朝向手势不接管路线、点云编辑、楼梯编辑、只读或重定位工具。
6. 选点不自动移镜头，手势期间冻结镜头跟随和 Orbit 阻尼。朝向更新复用现有箭头，只改变方向，不重建标记或文字纹理。

## 点击目标与规划终点

`pendingGoal` 保留用户选定的机身目标位置。服务端 `preview.goal` 是请求点，不能作为实际规划终点。
仅使用当前、成功且可行的 `preview.path` 最后一项作为“规划终点”；显示两个位置、连线和三维偏移。
返回路径缺失、非有限或请求点不匹配时，不显示假终点，也不允许用该预览确认导航。
两点重合时只显示一个点和箭头，不叠加重复标签；坐标和“重合”收在目标详情中。有偏移时主卡显示短提示，场景保留双点和标签。
位置变化只能称“端点偏移”，响应未提供原因时不称为已证实的吸附。
不把规划终点自动覆盖用户请求；确认仍发送用户原始目标及选定朝向，由原生导航重新判定。

## 拒绝原因定义

| 层级 | 原始事实／代码 | 用户说明 |
| --- | --- | --- |
| 选点 | 未命中表面、缺目标高度或机器人支撑高度 | 重新选可见表面或等待有效高度，不能填假Z |
| 地图 | active_octomap_not_configured、planner_map_identity_missing | 当前导航地图未就绪 |
| 地图变化 | active_map_changed_during_planning、frame_epoch_changed | 地图或坐标已改变，需要重新预览 |
| 定位 | odometry_not_ready、map_odom_tf_not_ready、odom_missing/stale、tf_missing/stale | 定位或坐标变换未就绪／已过期 |
| 起点 | start_occupied、start_unsupported、start_temporary_obstacle、start_outside_static_map、start_snap_exhausted | 分别显示起点障碍、缺支撑、当前障碍、越界或无可执行起点 |
| 目标 | goal_outside_static_map | 目标超出当前地图范围 |
| 目标 | goal_snap_exhausted | 目标附近未找到满足支撑与通行条件的位置；不擅自细分为占据、未知或缺地面 |
| 路径 | support_disconnected、empty_path、goal_not_reached | 支撑未连通、没有可用路线、终点未满足目标容差 |
| 计算 | search_iteration_limit、preview_timeout、preview_cancelled、planner_error、planner_busy、navigation_busy | 预算用尽、超时、取消、规划错误或忙碌，不伪装成障碍物 |
| 提交 | native_command_rejected | 机器人明确拒绝，展示其真实reason_code |
| 提交 | native_command_unconfirmed | 未收到确认，先检查当前任务，不称为已拒绝或已停止 |
| 控制 | 只读、急停、人工接管等已有门禁 | 保留原门禁，不通过界面解除 |

已识别代码显示统一中文；完整原始原因可展开查看。未知原因保留原文供诊断，主提示不猜故障原因。
仅预览路线不能证明机器人实际到达或末端旋转已通过实机验收。
